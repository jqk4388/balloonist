# 栅格引擎：怎么从一张漫画页里取出气泡

分析器实现在 `tools/raster/*.go`（纯 Go、零第三方包），编译成单文件静态二进制，同一份源码交叉编译三个目标：`BalloonistRaster.exe`（Windows x64）、`BalloonistRaster-osx-arm64`、`BalloonistRaster-osx-x64`。`BalloonistRaster.cs` 是移植前的 C# / `System.Drawing` 版本，保留作对照实现（两者命令行、请求/结果协议、数值输出逐字节一致）。

InDesign 端通过 `src/core/raster.jsx` 调用：写请求文件 → 后台启动分析器 → 每 20 ms 轮询结果 JSON。Windows 用 `WScript.Shell` 跑一个隐藏窗口的 `.vbs`；macOS 用 AppleScript 的 `do shell script` 起一个脱离的 `/bin/sh` 包装脚本（`BalloonistRaster` 启动壳按 `uname -m` 选对应架构的二进制）。

## 请求 / 结果协议

请求（`key=value`，一行一个）：

```
img=<页面图的绝对路径>   # 页面导出图（InDesign 自己导，含矢量与置入图）
scale=2                 # px/pt（144dpi 时是 2）
pad=0.035               # 安全框内边距 = 短边 3.5%，最少 2px
thr=200                 # 白纸阈值（亮度）
dil=1                   # 白掩膜先腐蚀 1px = 墨线膨胀，封住抗锯齿缝
h=0.35                  # h-maxima 的 h（抗尾巴/细颈产生假种子）
dump=<临时目录>/dump.png # 可选，画调试叠加
mode=frames             # 或 bubbles（整页普查）
minside=0               # 普查：气泡短边下限(pt)，0 = 按短边百分比
minarea=0               # 普查：面积下限(pt²)，0 = 按页面积百分比
maxarea=0.09            # 普查：面积上限（占整页比例）
maxaspect=3.5           # 普查：长宽比上限
ring=0                  # 普查：轮廓墨线占比下限（0 接受涂白无描边的气泡）
rect=x1,y1,x2,y2        # 每行一个，文本框的页面点坐标（mode=frames）
```

结果（`{"ok":true,"results":[...]}` 或 `{"ok":true,"bubbles":[...]}`），每个条目：

```json
{ "ok": true, "leak": false, "area": 210514,
  "center": [283.03, 151.20],        // 本体质心（页面点）
  "radius": 236,                      // 本体内最大内切半径(px)
  "bbox": [147.5, 24.5, 401, 281.5],  // 本体外接框
  "fitRect": [181.0, 99.9, 385.1, 202.5],  // 以质心为中心的最大内接安全框
  "openRays": 0,                      // 轮廓"漏气"的射线数
  "dbg": "comp=539791 lobe=210514 seeds=29 shortSide=507 r14=70.98 ...",
  "poly": [[x,y], ...] }              // 120 点本体内边（含内边距）
```

坐标一律是**页面点**；内部一律按像素算，进出各换算一次（`px = pt * scale`）。

## 流水线（`mode=frames`）

1. **白掩膜**：亮度 `>= thr` 记为"纸"。
2. **墨线膨胀**（`dil`）：对白掩膜做 1px 四邻腐蚀。扫描稿的黑线与网点的抗锯齿缝隙会让相邻气泡"漏气粘结"，腐蚀 1px 后每条轮廓都闭合。
3. **连通域**：给每一片纸标号，记面积、外接框、质心、是否触页边。
4. **选片**：在文本框矩形内每 3px 采一点投票（跳过占页面 >18% 的片区），票数最多的片区就是"这张气泡所在的纸"；没有票就取矩形附近最靠谱的那片。`leak` 表示投到的片区就是整页余白。
5. **填洞**：从图外泛洪，凡泛洪到不了的白像素算洞（气泡内部被黑字/网点打碎的纸重新变实心）。
6. **距离变换**（chamfer 3-4）：得到每个纸像素到最近墨线的距离 `d`。
7. **h-maxima 种子**：`recon = max(d - h*shortSide, 0)` 在 `d` 下做重建，取 `d - recon > 0.5` 的连通块作种子。直接按阈值取"核"会让尾巴和细颈各自长出一个极值，h-maxima 把它们吃掉，只留气泡本体。
8. **分水岭**：从种子在 `d` 上做优先队列泛洪，鞍点高度 `>= 99%` 两盆地较小极值的相邻盆地合并 —— 这一步把"一个气泡"合成一个盆地，而不是被黑字切成几块。
9. **取本体**：文本框投票选中的种子所在的盆地 = 气泡本体（尾巴在外面）。再对本体做一次距离变换。
10. **质心**：`d >= 14% 短边` 的像素的质心（TypeR 的 14% 收缩切尾）。这就是"居中的目标点"。
11. **安全框**：以质心为中心的矩形，二分搜索最大边长，条件是矩形内所有像素 `d >= padPx`（pad = 3.5% 短边，最少 2px）。
12. **轮廓**：120 条射线从质心往外走到 `d = padPx` 的位置，两次平滑，得到白块多边形（`clean` 用它覆盖原文）。

## 普查（`mode=bubbles`）

同一套流水线，对每一片"纸"跑一遍，然后按下列条件筛：

| 条件 | 插件默认 | 挡住的东西 |
|---|---|---|
| `basin / 外接框面积 >= 0.55` | 0.55 | 网点碎块、字腔 |
| `openRays <= 8` | 8 | 轮廓漏气的开口区域（页边余白、跨格空白） |
| `长宽比 <= maxaspect` | 3.5 | 条状格缝 |
| `短边 >= minside` | 0（按短边百分比） | 小字腔、标点框 |
| `minarea <= 面积 <= maxarea*页面` | 0（按页面积百分比）/ 9% | 整页余白、大块留白 |
| `轮廓墨线占比 >= ring` | 0 | 没有黑边的空白口袋 |

请求里省略这些键时，分析器自身回退到 `30 pt / 1500 pt² / ring 0.30`；插件总会显式发送配置值，所以以插件配置为准。

`ring` 的算法：对 `!本体` 做距离变换，取 `0 < d <= 28px` 的壳层，算壳层里"墨"（非纸）像素的占比。真实气泡有完整黑边，空白口袋没有。

单页合成样稿（1403×2048 pt）测试：检出 19 个气泡，安全框与重心稳定；另有 3 个误报（页边小黑块、两处空白口袋），把 `ring` 提到 0.35 或 `minarea` 提到 20000 可再压掉，代价是极小的气泡也一起没了。

## 调试图

`dump=` 指定路径时画叠加（只有 `mode=bubbles` / `blobs` 会写；`frames` / `box` 模式不画）：

- 绿 = 气泡轮廓 `poly`（≥3 点时画，2 px）
- 品红 = 安全框 `fitRect`（1 px）
- 红 = 重心十字（±8 px，2 px）

坐标是页面点 × `scale`。`dump=` 指向哪个路径，叠加图就写到哪里；仓库不附带任何调试图或真实页面。

## 性能

单页 2806×4096（约 1150 万像素）：单框 ~0.9 s，整页普查 ~3.5 s（含画叠加）。缓存交给 InDesign 端：相同 `page.id + 矩形签名 + 参数` 直接命中 `B.ops.cache`，一页只导出、只分析一次。
