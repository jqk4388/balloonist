# 与 TypeR 的对照

TypeR（ScanR，Photoshop 插件，UXP 面板 + 旧 CEP 版）的核心是"智能粘贴"：按一下，把剪贴板文字变成一个**贴在气泡里、按重心居中、字号刚好填满**的点文字层。Balloonist 把这套搬进 InDesign——好处是文字仍是**活文本**，可改、可搜、可导出 PDF/EPUB，嵌字不用再回到 PS 里做。

## 机制对照

| 环节 | TypeR 的做法 | Balloonist 的做法 |
|---|---|---|
| 拿到气泡形状 | 魔棒点选气泡内部，读**选区轮廓**（不是矩形） | 页面导出 PNG → 白纸距离变换 + h-maxima 分水岭 → 气泡本体 |
| 切掉尾巴 | 轮廓先收缩再生长（开运算），量为短边 14% | 距离变换上取 `d >= 14% 短边` 的核当本体，尾巴不进入本体 |
| 居中目标 | 本体质心（centre of mass），双联/三联取腔室中点 | 同：`res.center` = 本体质心 |
| 对齐动作 | 移动墨迹包围盒的中心到目标点 | 文本框（= 安全框）以目标点为中心落位，文字在框内 水平+垂直 居中 |
| 安全框 | 轮廓内缩 3.5% 短边（最少 2px） | 同：`pad=0.035`，二分搜索以质心为中心的最大内接矩形 |
| 字号阶梯 | 先取"放得下的最大字号"（0.5pt 步进），再依次试 2/3、1/3、基准、半、无 内边距，最后才允许极小的溢出 | `fitFrameToBubble`：关闭 auto-sizing，每次重置安全框，用框边界 + 实测墨迹双重检查，二分搜索最大可放字号（默认上限 600%；0=按气泡）；首行基线不动 |
| 连字符 | 允许一个连字符 | **未做**（下一版：断行建议） |
| 清原文 | "TypeR Clean" 图层上白色/黑色填充 | `Balloonist Clean` 图层上的白色多边形（`res.poly`，120 点） |
| 样式前缀 | `REG:` / `SFX:` / `THOUGHT:` 套不同字体 | **未做**（样式重排功能已移除，只保留全局字体） |
| 双/三口气泡 | 自动识别并拆成多腔，各腔独立居中 | **未做** |
| 字体扫描 | FontScanR / Font FindeR | **未做** |
| 断行建议 | TextShapeR：逐行测量墨迹，给出更均衡的断点 | **未做** |

## 有意不同的地方

1. **不做破坏性像素操作**：TypeR 输出点文字层（栅格化后无法回改）；Balloonist 输出文本框，字号、断行、字体随时可调，能直接出印刷 PDF。
2. **页面级普查**：`autoframes` 一次给整页气泡铺好框（TypeR 是逐口气泡手动点）。嵌字时只要往框里打字，框已经在对的位置。
3. **不改原稿**：白块在独立图层，删层即还原；TypeR 的 clean 也是独立层，但像素层删掉后原文已不可追（除非留底稿）。
4. **参数按页可调**：日漫网点密、气泡小，欧美漫气泡大，`minArea / ring / maxAspect / pad` 都在配置里，不用改代码。

## 合成样稿测试（非真实稿件，1403×2048 pt）

- 铺框：19 个气泡 → 19 个框；框全部落在 `fitRect`；字号按气泡大小给了起始值（24pt 基准）。
- 居中 + 适配：字号分布 16.5–44pt；其中一个 204×102.6pt 的安全框涨到 44pt 仍不溢出。
- 清原文：19 个白块，气泡黑边与尾巴完整保留，框内字全部可见（`post empties = 0`）。
- 唯一失败：69×107pt 的极窄气泡，20 个字缩到 75% 地板（16.5pt）仍差一行——这种要么手工断行，要么把 `minPct` 调到 0.6。
- 批量对齐：20 页合成样稿上 66 个文本框，绝大多数一次匹配成功；未匹配的主要是页边说明文字与极窄气泡。
