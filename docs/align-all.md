# 气泡居中（alignAll）

给**已经排好字**的稿子用：每个文本框自己找到所属气泡并移到气泡重心，让文字压在该在的位置。默认只做平移，**不动任何文字属性**——字号、行距、对齐、内边距、首行基线、框尺寸全部保持原样。

## 两条路径

| 场景 | 走哪条 | 关键区别 |
|---|---|---|
| 导入LPtxt的indd稿 | 气泡居中 | 批量、只移动、按墨迹重心校正 |
| 嵌字中的操作 | 适配气泡 | 将字号匹配气泡大小 |
| 有字图的indd稿 | 气泡涂白 | 批量涂白气泡 |

气泡居中会跳过 `SFX` 图层上的文字（拟声字本来就该压在画面上），这些框不参与匹配与位移。

## 流程

```
选中/整本 → 收集文本框 → 按页检测气泡 → 打分匹配 → 贪心分派 → 逐框位移
```

1. **收集**：`所有页` 开时取全文文本框；关时取选中项，没有选中则取当前页。`只处理有文字` 过滤空框。
2. **检测**：只对含框的页取图，`force` 跳过缓存。调用方（选项里的 `detect` / `lightThr` / `minFill` / `dpi`）覆盖全局配置；`dpi` 默认 150，0 表示沿用全局。
3. **匹配打分**（每页）：
   - 候选气泡按 `fitRect`（安全框）与**实测墨迹框**的交叠量、间距计算——成品稿里字常常挂在框外，用框比会算错，量字才准；
   - 墨迹落在安全框内的比例 ≥ `墨迹覆盖比下限`（默认 25%）→ `overlap`；
   - 否则交叠 ≥ 4% 框面积 → 次强候选；间距 ≤ `maxDist`（默认 48 pt）且勾了 `贴靠邻近气泡`（默认开）、框的宽高不超过气泡安全框的 2.5 倍 → `near`；
   - 其余不算候选。
4. **空间门槛**：只要求墨迹落在气泡内；文本框或文字比气泡大也照样匹配、照样居中，不再因为“安全框放不下”而跳过。
   - 墨迹面积 = 实测墨迹 `w*h` + `em²`，`em` 取框内最大字号（最小 8 pt）；
   - 竖排多列时按 `列数 × em × 1.15` 兜底估算宽度（`inkBox` 只量单列，会低估）。
5. **分派**：按候选强度排序（`rank` 高者优先，其次交叠多、间距小、气泡小），逐框贪心分配；一个气泡只给一个框，一个框只拿一个气泡。已被占用的目标安全框若与当前候选交叠超过 12%，当前候选作废——避免一分为二的椭圆气泡叠字。
6. **落位**（默认 `只移动`）：
   - 框中心平移到气泡重心；
   - 二次墨迹校正默认关（`按墨迹重心（实验）`）：竖排框的 `horizontalOffset` 在 InDesign 2025 上量不准，实测会把刚移好的框拉回原位，所以默认只按框中心；需要时可以打开做对比；
   - 全程不调用 justify / 不设内边距 / 不改字号。
   - 关掉 `只移动` 才会走"普通居中"路径：若同时勾了 `顺带套用安全框尺寸`，框会改成安全框大小，并对文字执行对齐与内边距归零；字号仍不动。
7. **报告**：`{pages, frames, inside, near, placed, failed, moved}`，状态栏给出「已对齐 N 个文本框（M 页）」。结果同时写入 `last-result.json`。

## 磁贴（只移动）为什么必要

成品稿里每个框的字号、行距、断行都是人定过的。任何"顺手"的居中对齐或内边距归零都会重新排版，行数一变整页就散了。所以默认路径只改一件事：位置。`顺带套用安全框尺寸` 与 `只移动` 互斥——只移动开着时它被忽略；关了只移动才会改框大小和对齐。`溢出时缩字号`、`最小/最大字号比例` 三个选项当前固定不生效：溢出问题交给人工改行，脚本不擅自改字号。

## 批量取图

- 需要分析的页 ≥ 4：一次 `EXPORT_ALL` 导全部页（避免逐页开关图层造成的闪烁，也规避逐页 `pageString` 的页码错误），再按页名/序号把文件映射回页面。
- 页数少：逐页 `EXPORT_RANGE` 导出。
- 批量导出一个文件都没产出（挂载、节、特殊页码命名都可能触发）：自动退回逐页导出。
- 导出前隐藏一次嵌字图层（`Balloonist Text`、`Balloonist Debug`、`Text`、`SFX` 及自定义 `hideLayers`），整轮结束再恢复一次。
- 缓存键包含页面 id、检测器、dpi、pad 与所有阈值；改参数后必须重扫，否则会静默复用旧气泡。

## 单位与页码

- 每次运行前强制 `app.scriptPreferences.measurementUnit = POINTS`。以毫米为标尺的文档会把 362×516 pt 的页报成 128×182，所有几何比较随之失效。
- 页面身份用 `page.name`（页面标签）。InDesign 2025 没有可用的 `Page.pageNumber` / `Page.documentOffset`，旧写法会算出第 0 页并触发「导出的页码设置无效」。
- 页面局部坐标：现代 InDesign 的 `geometricBounds` 本身就是页内坐标（原点 0,0）；`pageOrigin` 默认返回 0，只有检测到文本框落在页面外（老稿按跨页绝对坐标摆放）时才退回跨页左上角。

## 试算

勾 `只试算` 后不移动任何东西，输出每个框的匹配结果、目标气泡的文本与按页统计（命中/贴靠/未匹配）。调 `贴靠邻近气泡` 与 `最大距离` 前建议先跑一次试算，确认没有把页边说明文字吸到隔壁气泡上。

## 已知边界

- 文本框与任何气泡都不交叠、也不在 `maxDist` 内：不动，计入未匹配。
- 一页多个气泡共用一段文字（跨格长条）：只认第一个匹配，其余保持原样，需人工处理。
- 气泡极窄（安全框宽或高 < 12 pt）：检测结果直接丢弃，不对齐。
- 文本溢出气泡：脚本不改字号，需人工断行或用「适配气泡」单独处理。
- 旋转过的文本框只平移，不旋转；旋转稿需先摆正。

## 纯位移验证（合成样稿）

在一份抽象图形拼成的合成样稿上跑默认选项（`只移动` 开、`按墨迹重心` 关），逐框比对以下属性：

- `insetSpacing`
- `verticalJustification`
- `firstBaselineOffset`
- 段落 `justification`
- `pointSize`
- `appliedFont`

结果均为 0 变化，只有文本框位置发生平移。仓库不附带样稿、页面图或真实稿件；需要复现时请自行用几何图形生成测试页。
